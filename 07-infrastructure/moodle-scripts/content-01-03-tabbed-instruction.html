From Talking About Programs to Writing One

In 01.1 and 01.2 you talked about programs: what they are, how computers follow instructions literally, the Input-Process-Output pattern. Today that changes. You're going to write a real program, a real file on a real computer, and run it.

A program is just a plain text file containing statements: individual instructions, written in a language Python understands, that get carried out one at a time, top to bottom, in the exact order you wrote them. That "order matters" idea from 01.1 wasn't just a warm-up. It's literally how your file will run.

# this is a real Python statement
print("Hello, world!")

That single line is a complete, real program. Python reads it, runs it, and Hello, world! appears. You'll write your own version of this in the Coding Exercise that follows this lesson.

Your Primary Tool: VS Code

VS Code is where you'll write and run Python all year. The pieces you need right now:

  • A file with a .py extension — this tells VS Code (and Python) that the file contains Python code.
  • The editor pane — where you actually type your code.
  • The Run button (the ▶ triangle in the top-right of the editor) — runs your file from top to bottom.
  • The terminal / output panel — opens automatically when you run your file, showing exactly what your program printed.

Save your file before you run it. If VS Code doesn't seem to be running your latest changes, that's almost always the reason.
