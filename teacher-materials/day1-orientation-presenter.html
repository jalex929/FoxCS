Welcome to Python

Today:

  • Your tools, and how practice and problem-solving work in this class.

This isn't just a Python-syntax class. It's a game design class that happens to use Python as the tool for actually building things. Every unit this year connects the code you're learning to a real idea about how games work and how they're designed to feel a certain way to play.

Everyone in this course learns Python this year, the whole way through. There's no pathway choice to make here — this is your path, and it's a genuinely deep one: by the end of the year, you'll be able to build real, working programs and games from scratch, and you'll be prepared for an industry certification exam, IT Specialist – Python.

The MDA Framework

Open Lesson 0.1: Welcome →

Here's a lens you'll use all year, starting today, well before you've written any real code. It's called MDA, and it comes from real game design theory. It breaks a game down into three connected parts: Mechanics (the actual rules and systems), Dynamics (what happens when a player interacts with those rules over time), and Aesthetics (the feeling the player ends up with as a result). Pick a game you already know, and try naming one Mechanic, one Dynamic, and one Aesthetic.

Your Tools

Open Lesson 0.3: Using Your Tools →

You'll be working in Python and VS Code, both already installed on your computer. Get in the habit now: save your work with Ctrl+S constantly, not just when you're done. It costs nothing and it means you never lose more than a minute or two of work if something goes wrong.

How Practice Works Here

Open Lesson 0.2: How Learning Works →

Practice in this course adjusts to what you actually need. If something clicked quickly, you'll move into more challenging material. If something needs more work, you'll get more practice with that specific thing before moving on. Everybody in the room may be doing something a little different at any given moment, and that's normal — it's not a sign you're behind.

When Something Breaks

Open Lesson 0.4: Troubleshooting Is Learning →Open Lesson 0.7: Getting Unstuck →

Troubleshooting is learning, not a sign something's gone wrong. When you hit an error, work through it: understand what you're trying to accomplish, plan before you build, try the smallest useful version first, check the result against what you expected, and revise. If you're still stuck after trying that yourself, asking a classmate first is a genuinely good option, not a fallback — as long as you know how to ask well: a specific question, and what you've already tried. After that, ask your teacher.

Academic Integrity

Open Lesson 0.8: Academic Integrity →Open the Check →

To start the year, we will not be using AI in our work. Not your code, not your written responses, not any part of an assignment you submit as your own. When an assignment is partner work, both people actually do the work — if a partnership breaks down and one person ends up doing all or almost all of it, only the partner who did the work gets credit; the other restarts the assignment on their own. If a classmate asks you for help, actually helping means explaining how to think through the problem, not handing over your file to copy — and handing it over carries the same consequence as cheating does, for both people involved.

If This Line Gets Crossed
  1. A call or email home.
  2. A written record of the incident, logged in Aspen, which leads to a conversation with a member of the school's Disciplinary Team.
  3. A 0% on the assignment, which cannot be made up.

Genuine effort always earns credit, even when the work is incomplete or wrong. A real, honest attempt that doesn't fully work is worth more than a submission that skipped the effort entirely. Even when you don't get it right, trying it yourself will always earn you more points than cheating would — that's true on purpose, it's the whole point of how this is set up.

Game Design/Unity · Day 1

Welcome to Game Design/Unity

Today:
  • What this course covers, and the pathway choice ahead of you.
  • Your tools, and how practice and problem-solving work in this class.
  • Academic integrity — what's expected, and what happens if that line gets crossed.

Here's the choice ahead of you: Web Dev or Game Design/Unity. You haven't chosen yet, and that's fine — today is about getting oriented, not deciding right now.

This Choice Isn't About Which Class You're In

Game Programming II and Web Design II share this exact room, at this exact time. You're not split into two separate classes making two separate decisions — you're one room full of people, and everyone here gets to pick whichever pathway actually excites them. A Game II student can choose Web Dev. A Web II student can choose Game Design/Unity. Whichever way you go, pick the one you're actually excited about.

The Two Pathways

Open Lesson 0.9: Choosing Your Pathway →
Game Design / Unity Pathway

You'll design and build real games in Unity, using C# — mechanics, player experience, level design, and eventually moving from 2D into 3D. Everyone starts with a few weeks of game-design basics and a simpler tool called MakeCode Arcade, before moving into Unity itself. You'll work toward Unity Certified User Programmer, a required credential, and Unity Certified User Artist is achievable on top of that if you keep yourself moving and use class time well.

Web Dev Pathway

You'll build real, usable websites and web applications with HTML, CSS, and JavaScript — understanding what a real person needs, testing whether your design actually works for them, and revising based on what you find out. You'll work toward a JavaScript certification, required first, with HTML5 Application Development as an encouraged second credential once you're further along.

Get your pathway's core content done first — that's the priority, and it comes before anything below. Once it's out of the way, if you keep working diligently, the rest of the year is yours: finish your pathway's second credential, cross over and explore the other pathway, or go deeper into whatever you find genuinely interesting. Here's the fuller set of credentials available across this room:

JavaScript HTML5 Application Development Unity Certified User Programmer Unity Certified User Artist Unity Certified User VR Developer
