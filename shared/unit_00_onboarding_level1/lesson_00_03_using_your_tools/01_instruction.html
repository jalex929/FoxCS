Getting Started

0.3 — Using Your Tools

What you'll take away:
  • I can confirm that Python and VS Code are working correctly on my computer.
  • I can create, save, and run a Python file.

Everything you build in this course happens in two main tools: Python, the programming language itself, and VS Code (Visual Studio Code), the editor you'll write it in. Both are already installed on your computer. Let's confirm they're working before you need them.

Confirm Your Setup
  1. Open VS Code.
  2. Create a new file, save it as hello.py, and type print("Hello, World!").
  3. Run it. In VS Code, this is usually the green Run arrow in the top right, or right-click the file and choose "Run Python File in Terminal."
  4. You should see Hello, World! appear in the terminal at the bottom of the screen. If you do, everything is working correctly.
  5. If something doesn't work, tell your teacher right away instead of trying to fix it on your own.
Save Often

Get in the habit now: save your work with Ctrl+S constantly, not just when you're done. It costs nothing and it means you never lose more than a minute or two of work if something goes wrong.

What To Do Next
