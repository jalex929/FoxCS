0.3 — Using Your Tools

What you'll take away:
  • I know what Python and VS Code are for, even before I've opened them myself.
  • I know I'll confirm my setup works once the software is actually installed on my computer.

Everything you build in this course happens in two main tools: Python, the programming language itself, and VS Code (Visual Studio Code), the editor you'll write it in. These aren't installed on your computer yet — your teacher will let you know when they're ready. For now, just know what each one is for; the hands-on setup check happens later, once the software is actually there.

Confirm Your Setup (Later, Once VS Code Is Installed)

When your teacher tells you VS Code and Python are ready on your computer, come back to this page and run through these steps:

  1. Open VS Code.
  2. Create a new file, save it as hello.py, and type print("Hello, World!").
  3. Run it. In VS Code, this is usually the green Run arrow in the top right, or right-click the file and choose "Run Python File in Terminal."
  4. You should see Hello, World! appear in the terminal at the bottom of the screen. If you do, everything is working correctly.
  5. If something doesn't work, tell your teacher right away instead of trying to fix it on your own.
Save Often

Get in the habit now: save your work with Ctrl+S constantly, not just when you're done. It costs nothing and it means you never lose more than a minute or two of work if something goes wrong.

What To Do Next
