0.9 — Choosing Your Pathway

What you'll take away:
  • I understand what each pathway actually involves, and how they're alike and different.
  • I've chosen the pathway I'm going to follow, or decided to work across more than one.

Here's the choice: Web Dev, Game Design/Unity, or Software Development. Read all three descriptions below, then decide.

This Choice Isn't About Which Class You're In

Game Programming II and Web Design II share this exact room, at this exact time. You're not split into separate classes making separate decisions, you're one room full of people, and everyone here gets to pick whichever pathway actually excites them. A Game II student can choose Web Dev. A Web II student can choose Game Design/Unity. Neither pathway belongs to one class, because in the room you're sitting in right now, there isn't really a line between them.

If you're enrolled in both Game II and Web II, you have an extra option: go deep on just one pathway, or split your time and work across more than one. That's genuinely up to you. Whichever way you go, pick what you're actually excited about.

Web Dev Pathway

You'll build real, usable websites and web applications with HTML, CSS, and JavaScript. This pathway is about more than making a page look right. You'll learn to design for a real person using what you build: understanding what they need, testing whether your design actually works for them, and revising based on what you find out.

Game Design / Unity Pathway

You'll design and build real games in Unity, using C#. This pathway is about the full craft of game design: mechanics, player experience, level design, and eventually moving from 2D into 3D. You'll work toward an industry certification along the way.

Software Development Pathway

You'll go deeper into the ideas behind Web Dev's tools instead of just using them: HTML + CSS, then JavaScript, then HTML5 Application Development, then Java, then Software Development itself. This pathway is for anyone genuinely interested in programming, computer science, application development, and software engineering as a field, not just building one website or one app. It's certification-heavy: each stage builds a credential and real conceptual depth toward the next one, including learning an entirely second programming language (Java) once you're ready.

How They're Alike

  • All three are real, project-based work. You'll spend most of your time actually building something, not just reading about how to build it.
  • All three lead toward real industry certifications, with a required credential and further ones you can add if you keep yourself moving.
  • All three are built around a real person using what you make, or a real problem being solved well. Web Dev calls this usability. Game Design/Unity calls it player experience. Software Dev calls it good software design. Different name, same core habit: build it, test it, revise based on what you learn.
  • All three use the same approach to practice from Lesson 0.2, and the same troubleshooting and problem-solving process from Lessons 0.4 and 0.6.

How They're Different

  • Where you start. Web Dev has a way to show you already know HTML and CSS well and move faster into JavaScript. Game Design/Unity doesn't work that way, since Unity itself is new territory for almost everyone — instead, everyone starts with a few weeks of game design basics and a simpler tool called MakeCode Arcade, before moving into Unity itself. Software Dev builds on the same HTML/CSS/JavaScript foundation as Web Dev, then keeps going past it.
  • The shape of the year. Web Dev is a fairly steady climb: HTML, then CSS, then JavaScript, building in complexity the whole way. Game Design/Unity has one big structural shift partway through the year, when you move from building 2D games into 3D. Software Dev has the biggest shift of the three: partway through, you start learning an entirely second programming language, Java, on top of everything from the web side.
  • How much ground gets covered. Web Dev runs 21 units, Game Design/Unity runs 29. Software Dev's total unit count isn't set yet — this line will get a real number once that pathway's own course plan is built. Not guessed here on purpose.
  • Software Dev is the one pathway with real prerequisites. You'll need to make substantial progress through Web Dev's certification content before Software Dev's own deeper material really applies — it's less of a same-day starting choice than the other two, more of a "keep going" option once you're already moving through the web track.
If You're Leaning Toward Game Design/Unity

You'll spend a lot of this year using a lens called MDA: Mechanics (the rules), Dynamics (what actually happens when players interact with those rules), and Aesthetics (how it all feels to play). You don't need to know anything about it yet, but it's worth knowing the name now, since it's coming.

If You're Leaning Toward Web Dev

You'll spend a lot of this year asking one central question about everything you build: can another person actually understand and use this? That's usability, and it's just as much a real design skill as the code itself.

If You're Leaning Toward Software Dev

You'll spend more of this year on the "why" behind the code than the other two pathways — how software actually gets designed, built, tested, and maintained, not just how to make one page or one app work. It's the pathway for anyone who wants to keep going deeper into programming itself as its own field.
