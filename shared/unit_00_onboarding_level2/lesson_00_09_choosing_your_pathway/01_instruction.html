0.9 — Choosing Your Pathway

What you'll take away:
  • I understand what each pathway actually involves, and how they're alike and different.
  • I've chosen the pathway I'm going to follow, or decided to work in both.

Here's the choice: Web Dev or Game Design/Unity. Read both descriptions below, then decide.

This Choice Isn't About Which Class You're In

Game Programming II and Web Design II share this exact room, at this exact time. You're not split into two separate classes making two separate decisions, you're one room full of people, and everyone here gets to pick whichever pathway actually excites them. A Game II student can choose Web Dev. A Web II student can choose Game Design/Unity. Neither pathway belongs to one class, because in the room you're sitting in right now, there isn't really a line between them.

If you're enrolled in both Game II and Web II, you have an extra option: go deep on just one pathway, or split your time and work in both. That's genuinely up to you. Whichever way you go, pick the one you're actually excited about.

Web Dev Pathway

You'll build real, usable websites and web applications with HTML, CSS, and JavaScript. This pathway is about more than making a page look right. You'll learn to design for a real person using what you build: understanding what they need, testing whether your design actually works for them, and revising based on what you find out.

Game Design / Unity Pathway

You'll design and build real games in Unity, using C#. This pathway is about the full craft of game design: mechanics, player experience, level design, and eventually moving from 2D into 3D. You'll work toward an industry certification along the way.

How They're Alike

  • Both are real, project-based work. You'll spend most of your time actually building something, not just reading about how to build it.
  • Both lead toward a real industry certification, with a required credential and a second one you can add if you keep yourself moving.
  • Both are built around a real person using what you make. Web Dev calls this usability. Game Design/Unity calls it player experience. Different name, same core habit: build it, test it on a real person, revise based on what you learn.
  • Both use the same approach to practice from Lesson 0.2, and the same troubleshooting and problem-solving process from Lessons 0.4 and 0.6.
  • Both eventually offer real choice in how open your projects can be, from a more guided build to a fully independent one, once you've got the basics down.

How They're Different

  • Where you start. Web Dev has a way to show you already know HTML and CSS well and move faster into JavaScript. Game Design/Unity doesn't work that way, since Unity itself is new territory for almost everyone. Instead, everyone starts with a few weeks of game design basics and a simpler tool called MakeCode Arcade, before moving into Unity itself.
  • The shape of the year. Web Dev is a fairly steady climb: HTML, then CSS, then JavaScript, building in complexity the whole way. Game Design/Unity has one big structural shift partway through the year, when you move from building 2D games into 3D.
  • How much ground gets covered. Web Dev runs 21 units, Game Design/Unity runs 29. Neither number means one pathway is harder than the other, they just lead to different destinations and cover what each of those destinations actually needs.
If You're Leaning Toward Game Design/Unity

You'll spend a lot of this year using a lens called MDA: Mechanics (the rules), Dynamics (what actually happens when players interact with those rules), and Aesthetics (how it all feels to play). You don't need to know anything about it yet, but it's worth knowing the name now, since it's coming.

If You're Leaning Toward Web Dev

You'll spend a lot of this year asking one central question about everything you build: can another person actually understand and use this? That's usability, and it's just as much a real design skill as the code itself.

Journal (50-75 words)

Which pathway are you choosing, or are you planning to work in both? Give one honest reason for your choice, based on what you actually want to build this year, not what you think sounds impressive.

What To Do Next

  1. Make your choice and write your journal entry above.
  2. Let your teacher know which pathway you're following.
  3. Once your pathway is set, your teacher will point you to that pathway's Unit 1.
Save your journal entry before moving on.
