0.3 — Using Your Tools

What you'll take away:
  • I know what tools each of my two pathway options uses, even before the software is installed on my computer.

You haven't chosen your pathway yet (that's Lesson 0.9, coming up soon). The software for both options isn't installed on your computer yet — your teacher will let you know when it's ready. For now, this lesson just introduces what each pathway's tools are and what they're for. The hands-on setup check below happens later, once the software is actually there.

Web Dev Pathway: Confirm Your Setup (Later, Once VS Code Is Installed)

If you end up choosing Web Dev, you'll build with HTML, CSS, and JavaScript, in a code editor called VS Code, and check your work in a browser. When your teacher tells you VS Code is ready, come back here and run through this check:

  1. Open VS Code.
  2. Make sure you have a modern browser available (Chrome, Edge, or Firefox all work fine).
  3. Create a new file and save it as index.html.
  4. Type a few lines of basic HTML. If you don't remember any HTML yet, that's completely fine, you don't need to know it for this check. Just copy the sample below into your file and save it.
  5. Open the file in your browser to see it render. If a page shows up with the heading and text from the sample, everything is working correctly.
<!DOCTYPE html>
<html>
<head>
<title>My Page</title>
</head>
<body>
<h1>Hello, World!</h1>
<p>This is my first web page.</p>
</body>
</html>
Game Design / Unity Pathway: Confirm Your Setup (Later, Once Unity Is Installed)

If you end up choosing Game Design/Unity, you'll build with a program called Unity, using a language called C#. When your teacher tells you Unity is ready, come back here and run through this check:

  1. Open Unity Hub.
  2. Confirm you can create a new project. You don't need to build anything yet, just confirm it opens.

Once the software is installed and you've tried the check above, if anything doesn't work, tell your teacher right away instead of trying to fix it on your own.

Save Often

Whichever pathway you end up on, get in the habit now: save your work with Ctrl+S constantly, not just when you're done. It costs nothing and it means you never lose more than a minute or two of work if something goes wrong.

What To Do Next

  1. Get both setups working using the steps above.
  2. Continue to Lesson 0.4: Troubleshooting Is Learning.
