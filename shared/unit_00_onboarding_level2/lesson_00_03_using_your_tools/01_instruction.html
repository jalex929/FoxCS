0.3 — Using Your Tools

What you'll take away:
  • I know what tools each of my two pathway options uses, and I have them ready either way.

You haven't chosen your pathway yet (that's Lesson 0.9, coming up soon), so this lesson sets up the tools for both options. Once you choose, you'll only need to actually use one of these, but it's worth having both ready now so you're not scrambling later.

Web Dev Pathway Setup

If you end up choosing Web Dev, you'll build with HTML, CSS, and JavaScript, in a code editor called VS Code, and check your work in a browser.

  1. Install VS Code from code.visualstudio.com if it isn't already on your computer.
  2. Make sure you have a modern browser available (Chrome, Edge, or Firefox all work fine).
  3. Create a new file, save it as index.html, type a few lines of basic HTML, and open it in your browser to see it render. If a page shows up, you're set.
Game Design / Unity Pathway Setup

If you end up choosing Game Design/Unity, you'll build with a program called Unity, using a language called C#.

  1. Install Unity Hub from unity.com/download if it isn't already on your computer (check with your teacher first, school machines may already have it).
  2. Through Unity Hub, install the latest recommended Unity Editor version.
  3. Open Unity Hub and confirm you can create a new project. You don't need to build anything yet, just confirm it opens.
Save Often

Whichever pathway you end up on, get in the habit now: save your work constantly, not just when you're done. It costs nothing and it means you never lose more than a minute or two of work if something goes wrong.
