This Week: Your Pathway Certification Work

Last updated: 2026-09-14. This page gets refreshed every week or two with your current focus -- check back rather than assuming last week's directions still apply.

Work from the box below that matches the pathway you chose (Game Design/Unity, Web Development, or Software Development). If you haven't chosen a pathway yet, go back to Choose Your Pathway in the section above before starting here.

Game Design / Unity

This week, work on your game in Microsoft MakeCode Arcade.

  1. Open MakeCode Arcade and either continue an existing Skillmap game, or create/remix your own.
  2. If you're not sure where to start, use one of the recommended Skillmaps under Next Level Skillmaps inside MakeCode.
Web Development & Software Development

If you've already earned your HTML & CSS certification: work on JavaScript, Domains 1 and 2, in GMetrix.

If you have NOT earned your HTML & CSS certification yet: work on Domains 1 and 2 of the HTML & CSS certification in GMetrix instead.

Either way, do this before you start coding:

  1. In GMetrix, download the Student Support Files for whichever certification you're working on.
  2. Extract (unzip) the downloaded files onto your computer.
  3. Open that extracted folder in VS Code.

Then follow along with the coding exercises covered in GMetrix's own videos for that domain, working inside the files you just opened in VS Code.
