1.4.1 — Instruction: Printing Output

Learning objectives:
  • I can write a correct print() statement and predict what it will display.
  • I can identify and fix a missing quote or missing parenthesis error.
Language objective:
  • I can describe the parts of a print() statement using the terms function, string, and argument.

What Does print() Do?

print() is a built-in Python function that displays output to the screen.

When Python runs print("Hello"), it takes the text inside the quotes and writes it out where you can see it. That text is called a string: any sequence of characters wrapped in quotes.

print() is your program's only way of talking to whoever is running it. Without it (or something like it), a program could do all kinds of correct work internally and whoever's watching the screen would never know. No output means no way to tell what happened.

Anatomy of a print() Statement

Every print() statement has three required parts:

  1. The word print. Always lowercase
  2. Parentheses (). These tell Python you're calling the function
  3. A string inside quotes. The text you want to display
print("Hello, World!")

If any part is missing or misspelled, Python won't run the line at all. It'll raise a SyntaxError before your program even starts. More on both common ways this happens below.

Quick Check
Which of these three required parts is missing from print "Hello"?

Why parentheses? If you ever see old Python code online written as print "Hello" with no parentheses, that's Python 2, an older version. In Python 3 (what this course uses), print is a function, and every function call needs parentheses.

If you copy code from an old tutorial and it uses print without parentheses, that's why it won't run here.

Reading a print() Statement Line by Line

print("Learning Python is fun!")

Python sees print and knows to call the print function → sees ( and starts reading what's being passed in → sees "Learning Python is fun!", a string in quotes → sees ) and knows the input is complete → displays: Learning Python is fun!

Two Mistakes Everyone Makes at First

Common Mistake
Forgetting to close the quote
print("Hello, Python!)

Python will show something like SyntaxError: EOL while scanning string literal. EOL means "End Of Line". Python reached the end of the line while still looking for the closing quote — notice the ) is right there, but it doesn't help, because it landed inside the never-closed string instead of ending the function call.

Before you click reveal: what one character would fix this line? Picture it in place, then check yourself.

print("Hello, Python!")

In red: the one character that was missing. Everything else on the line is unchanged.

Common Mistake
Missing parentheses
print "Hello"

Python 3 will show SyntaxError: Missing parentheses in call to 'print'.

Before you click reveal: what two characters would fix this line, and where would they go? Picture it, then check yourself.

print("Hello")

In red: the two characters that were missing. Everything else on the line is unchanged.

Neither of these means you did something wrong as a learner. They mean Python found a genuine grammar rule it needs followed exactly. Reading the error message is how you find out which rule.

Game Connection
This is your first real usability idea, not just a syntax rule

print() is your program's simplest form of feedback to whoever is using it, the same role a game's UI plays when it tells a player "Enemy defeated!" or "Not enough gold."

A program that prints 1 when something fails and 0 when it succeeds is technically giving output, but it's terrible output. Nobody looking at the screen can tell what happened without memorizing a code.

Specific, readable output is better than vague output. For example: if a player tries to buy something they can't afford, a message like "Not enough gold. You need 20 more." tells them exactly what happened and what to do next. A message like "Error 402" or nothing at all tells them nothing — they'd have to already know what that code means, or guess.

You'll come back to this idea properly once you've learned enough Python to actually handle errors gracefully (Unit 14). For now, just notice that the words you choose inside print() already matter.

Sneak Peek: What's Coming in Unit 05

You haven't learned if statements yet, that's Unit 05, but here's a short preview since this lesson's practice includes one. An if statement lets a program make a decision: if some condition is true, run the indented line(s) below it; if it's not true, skip them.

if health <= 0:
    print("Game Over")

The colon : ends the if line. The indented print(...) line only runs when health <= 0 is true, that's how Python knows it belongs to the if instead of being just the next unrelated line. You'll practice building exactly this pattern in this lesson's practice — all the teaching for it is right here, so if the item is confusing, this is what to re-read.

Key Terms

function
A named, reusable block of code that performs a specific task. print() is a built-in function.
Example: You'll start writing your own functions in Unit 08. For now, you're just using ones Python already provides, like print().
Think of it like: a vending machine. You press one button and it always performs the same task, without you needing to know how the machine works inside.
string
Text data surrounded by quote marks. 'Hello' or "World".
Note: The quotes matter. print(Hello) with no quotes tries to run Hello as code instead of displaying the word.
Think of it like: air quotes in a conversation. They tell Python "take this literally as text, don't try to interpret it as an instruction."
output
Text or data that your program displays to the screen.
Example: Every line that appears in the terminal after you run your program is output.
argument
The value you pass into a function. In print("Hello"), "Hello" is the argument.
Example: In print("Game Over"), "Game Over" is the argument, the specific text this particular call to print() should display.
Think of it like: texting a friend "meet me at 3pm." "Meet me" is the general instruction (the function); "3pm" is the specific detail you're handing over along with it (the argument).
SyntaxError
An error Python raises when your code breaks a grammar rule. Like a missing quote or parenthesis.
Example: print("Hi! (no closing quote) or print "Hi!" (no parentheses) both raise a SyntaxError before your program even starts.
Think of it like: a sentence missing its closing quotation mark in English. The reader (or here, Python) can't tell where the quoted part is supposed to end.
