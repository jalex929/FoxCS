01.4 Project: Status Message Board

A short applied task before the mastery check. This one applies the usability idea from the instructional page's Game Connection section: specific, readable output is better than vague output, even when both are valid Python.

The Task

Write a short program that acts like a game's status board: a few print() statements showing things like health, score, and level. Then add one more piece of output that reports a problem (out of moves, low health, item not available) using a clear, specific message, not a bare code or number.

What This Could Look Like

Here's the output a finished status board might display when you run it, just to show the shape of what you're building. This isn't code to copy, and yours doesn't have to look anything like this one, different status information and a different problem are both fine.

Health: 85/100
Score: 1,240
Level: 3
Not enough gold. You need 20 more to buy that.

Hint 1: Think of it as separate, independent pieces of information: health, score, level, and one specific problem message. Each one is its own print() statement, the exact same pattern from this lesson's drills, just with wording you choose.

Hint 2: Start with just one line. Write a single print() statement for the player's health, something like a number out of 100, run it, and check it displays what you expect. Once that one line works, repeat the exact same pattern for score, then level, before adding the problem message last.

Hint 3: A shape to fill in, not a solution — the actual print() statements and the wording are yours to write.

# Print the player's health

# Print the player's score

# Print the player's level

# Print one specific, readable problem message

Game Connection

Good games tell the player exactly what's wrong in words a player understands, not a bare code or number. "Not enough gold. You need 20 more." tells the player what happened and what to do about it. "Error 402" tells them nothing without looking it up. Here, you're the one deciding what specific, readable message to write, not just reading an example of one.
