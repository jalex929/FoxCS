Unit Project

1.6.5a — Project Instructions: Bug Hunt Challenge

A short applied task before the mastery check. This one is your first real QA pass: a whole small program, broken in several places, that you have to fix line by line.

The Task

Open 06_project.py. It's supposed to print a short game intro, but every line has exactly one mistake from this unit's Big Four (missing quote, missing parentheses, wrong capitalization, missing quotes entirely). Fix every line so the program runs and produces the intended output shown in the comments.

What This Could Look Like

Here's the kind of intended output your fixed program should eventually produce, using different wording than what's actually in your project file:

Welcome, challenger!
Choose your weapon
Good luck!

Hint 1: Fix and run one line at a time. Don't try to spot every mistake before running anything, let Python's own error messages guide you to the next problem.

Hint 2: For each broken line, check it against the Big Four table on the instruction page, in this order: quotes matched? parentheses matched? print lowercase? text actually in quotes?

Hint 3: A reminder of the process, not the actual fixes:

# Fix line 1, run it
# Fix line 2, run it
# Fix line 3, run it
# Fix line 4, run it
