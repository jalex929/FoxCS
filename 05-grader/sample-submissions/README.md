### Building the telemetry

`04_vocab_quiz_completed.html` and `05_practice_completed.html`'s hidden `foxcs-telemetry` blocks were hand-written to match the exact event shape `telemetry-and-analytics.md` specifies (`quiz_check`/`drill_attempt`, real timestamps, real attempt numbers) — not generated by actually running the pages. If the schema in those pages changes, this fixture's telemetry blocks will drift out of sync and should be regenerated to match.

### Regenerating or extending

If the real lesson content changes (new drills, renamed fields, a new save convention), this fixture will go stale. There's no automated sync — it was hand-built once against the state of `courses/python/content/unit_01_what_is_programming/lesson_01_04_printing_output/` as of 2026-08-11. Treat it as a snapshot, not a live mirror.
