Unit Project

1.1.4 — Practice

Quick practice with immediate feedback. This is 8 questions. This page is saved and submitted — your exact path through it (which questions, how many tries) is what this records, so it's fine if your path looks different from a classmate's. This isn't a race to finish fast.
Choose the Best Answer
Which of these best describes what a program is?
Right! A program is a set of exact, ordered instructions a computer follows.
Select All That Apply
Check all of the following that are examples of computer programs.
Right! A calculator app, a video game, and a weather app are all programs. A printed book doesn't run or follow instructions on a computer.
Fill in the Blank
The person who writes the instructions that make up a program is called a ______.
Right! A programmer is the person who writes the instructions.
Fill in the Blank
A single step in a program that tells the computer exactly what to do is called an ______.
Right! An instruction is a single step a program tells the computer to follow.
Choose the Best Answer
When a computer runs a program, it ___.
Right! Computers are very literal. They do exactly what the instructions say, no more, no less.
Predict What Happens
A vending machine's program includes this instruction: "If the amount inserted is less than the price, do not release the item." A student inserts less than the price. What will the machine do?
Right! The machine follows its written instruction exactly. It doesn't decide anything on its own.
Fill in the Blank
Python is an example of a programming ______.
Right! Python is a programming language, a tool for writing instructions a computer can carry out.
Choose the Best Answer
Which of these is the best reason a printed book is not a computer program?
Right! A program has to actually run on a computer and follow instructions. A book just sits there, being read.
