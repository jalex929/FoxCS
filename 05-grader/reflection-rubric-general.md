# General Reflection / Free-Response Rubric

**Added 2026-08-31**, per Jay: as Lesson 1 content gets authored across all 4 CS pathways, every activity type needs a parallel grading standard alongside it — projects and mastery checks get their own specific rubrics (per `05-grader/feedback-and-grading-spec.md`'s existing rule that a provided rubric is always the primary source of truth), but short reflections/journal entries/free-response prompts don't each need a bespoke rubric reinvented from scratch. This is that shared, reusable standard — apply it to any reflection-type activity (journal entries, essay-block reflections inside an Interactive Book, Game of the Week reflections, etc.) unless a specific lesson explicitly needs something more tailored.

**Not a replacement for `feedback-and-grading-spec.md`** — that document's voice/tone/output-format rules, human-review triggers, and Release Gate requirement still apply in full. This is specifically the *scoring criteria* to use for the "reflection" category of evidence that doc already references but doesn't itself define in rubric form.

## The Four Criteria

Score each reflection against these four, matching the existing journal-grading philosophy already established for Python's journal thread (`courses/python/course-plan.md`'s Journal Threads section) and Game of the Week's reflections (lighter-touch, genuine-engagement grading, never literary/grammar quality):

1. **Answers what was actually asked.** The response addresses the real question/prompt, not a generic restatement of the topic or a tangent. A thoughtful answer to the wrong question still fails this criterion.
2. **Meets the stated length target.** Word-count minimums scale per unit/lesson per the existing progression (50-75 words in Unit 00, growing across the year — see `course-plan.md`'s word-count table for Python; other pathways should define their own comparable progression as their journal threads get built). Meeting the target is necessary but not sufficient on its own — a response that hits the word count but fails the other three criteria still isn't a strong reflection.
3. **Shows genuine, specific engagement.** Rooted in the actual lesson/unit content just covered, not a generic pre-existing opinion that could have been written without doing the lesson. Concrete and specific beats vague and general — a reflection naming an actual example, detail, or moment from the lesson is stronger than one that stays abstract throughout.
4. **Sounds like the student's own voice and thinking.** Not a polished, generic-sounding response that reads as AI-generated or copy-pasted — see `01-privacy-and-governance/academic-integrity-ai-use.md` for the actual AI-use policy and its Level 1/Level 2 distinction (as of 2026-08-31, not yet formally updated in that doc — see `worklog.md`'s 2026-08-31 entries on Jay's stated AI-use scoping before assuming a specific boundary).

## Scoring Shape

Match `feedback-and-grading-spec.md`'s existing "best-fit, not perfection" philosophy — a reflection doesn't need to nail all four criteria equally to earn credit; use holistic judgment the same way project rubrics do, and flag genuinely borderline or concerning cases (suspected AI-generated text, a response that's off-topic, a response far under the word-count floor) for human review rather than silently passing or failing them.

This rubric is intentionally **completion/engagement-oriented, not literary-quality-oriented** — grammar and prose polish are not scoring criteria here, matching the existing rule that this is a CS/game-design/dev class, not a writing class, and grading prose quality would misrepresent the actual goal while blowing the 1-hour/week grading budget.
