Working examples of the illustration system defined in instructional-image-guide.md. This page is a reference tool, not lesson content. Every example below is a real, deployed pattern (linked at the bottom of each card to where it actually lives), shown here on its own so the visual language can be reviewed and reused without hunting through a full lesson page.
Micro Diagram · Concept: Variable
A named location holding a value. The label (score) stays connected to the box; the value inside (100) is what can change. Matches instructional-image-guide.md Section 12.2's own spec: "a named location, a label connected to a value, a value that may change while the name remains stable." Zero baked-in explanation text, exactly two labels (the variable name and its value), blue for structure, green for the value per the semantic color system.
Not yet deployed in a real lesson — Python's Unit 02 (Variables & Data) isn't built yet. This is the reference example for when it is.
