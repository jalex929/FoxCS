Theme + Telemetry Demo

This page is a reference tool, not lesson content. It exists to prove two mechanisms work: (1) swapping the linked theme file, reconciled at Save, and (2) a hidden interaction log accumulating as you use the page. Real lesson pages would never show the panel at the bottom — it's exposed here on purpose so it can be reviewed.

Natural and Synthwave now use the real palette from logos/waypoint_theme_typography_style_guide_full.md (see shared-styles/foxcs-theme-natural.css / -synth.css for the full reasoning). Colors are close to the current logo exploration but not final, since the logos themselves aren't final. Light and Dark reuse the already-approved palette from design-system.md.

Try both selection methods above, then click a lane-badge question below to generate some real events, then open the panel at the bottom to watch the hidden telemetry blob update live.
Saving rewrites #foxcs-theme-link's href to match whatever's currently selected, records a saves entry with that theme, and writes the whole page out — open the saved file and view source to see the theme link and the full telemetry JSON baked in.
