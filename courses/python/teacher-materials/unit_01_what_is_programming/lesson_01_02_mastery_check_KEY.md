# 01.2 Mastery Check: Input, Process, Output: rubric and answer key

**Never include this file in anything students can see.** Rewritten 2026-11-04 from the live quiz's own build script, so each item below is exactly what students are given. Replaces the earlier narrative key, which described questions the live quiz no longer asks.

**Live structure:** `build-lesson-01-02-mastery-check.php`. A pool of 10 essay tasks. Hand-graded.

## How every task is scored

The live Mastery Check is two questions: the **academic integrity acknowledgment** (always first; full credit for acknowledging it) and **one task drawn at random** from the pool below. Students get 3 attempts, and the attempts are averaged.

Unit 01 written answers use Jay's Sept 13 scale (`decisions-log.md`, 2026-09-13), because many students are English Language Learners and a real attempt shouldn't score 0:

| Score | The answer |
|---|---|
| 100% | Has every **Full credit needs** element for its task, stated clearly |
| 95% | Has every element, with one imprecise word or small slip |
| 90% | Gets the central idea right, but one required element is missing |
| 85% | A real attempt with one element right |
| 80% | A genuine attempt that restates the question or is mostly incorrect (the floor for any real attempt) |
| 0% | Blank, off-topic, or not a real attempt |

- **Grade the idea, not the English.** Spelling, grammar and word choice never cost a tier (`05-grader/comment-reasoning-rubric.md`, "What not to grade").
- **Expected answers are right or wrong.** Where a task has one (an output, a mistake's name, a term), mark it against the key and accept close paraphrases.
- **Every response gets feedback.** An 80-85% response gets a sentence starter specific to its task, never just "try again".

## Item 1

**Task:** A microwave: you set the time and press start, it heats the food, then it beeps when done. Identify the Input, Process, and Output, one sentence each.

**Full credit needs:**
- [ ] **Input:** setting the time / pressing start
- [ ] **Process:** heating the food (counting down)
- [ ] **Output:** the beep (and the hot food)

**Drops a tier:** two of three correct, or the three named but swapped.

**Watch for:** Calling the beep the Process.

**Sentence starter (80-85%):** "The input is ___. The process is ___. The output is ___."

## Item 2

**Task:** Explain why Input, Process, and Output happen in that order. What would break if Process happened before Input?

**Full credit needs:**
- [ ] The process needs something to work on, which comes from the input
- [ ] Process before Input would have nothing to work with (or would use missing or wrong data)

**Drops a tier:** restates the order without saying why it matters.

**Sentence starter (80-85%):** "Process has to come after Input because ___."

## Item 3

**Task:** A vending machine checks whether your money is enough, then dispenses or shows "Insufficient Funds." Where does the check fall, and why does it matter?

**Full credit needs:**
- [ ] **Expected answer: the Process stage**
- [ ] Explains that the check decides which Output happens (snack or the error message)

**Drops a tier:** places it in Input or Output, or names Process with no reason.

**Sentence starter (80-85%):** "Checking the money is part of the ___ stage, because it decides ___."

## Item 4

**Task:** Think of an app or device from your own life. Break it into Input, Process and Output, one sentence each.

**Full credit needs:**
- [ ] A real app or device
- [ ] A plausible Input, Process and Output, in order

**Drops a tier:** one stage missing or misplaced.

**Sentence starter (80-85%):** "In ___, the input is ___, the process is ___, and the output is ___."

## Item 5

**Task:** Explain the difference between Input and Output, using an example that shows you understand both.

**Full credit needs:**
- [ ] Input is what goes into the program (from the user or a sensor)
- [ ] Output is what comes out (shown, played, or done)
- [ ] One example shows both

**Drops a tier:** defines one only, or an example that mixes them up.

**Sentence starter (80-85%):** "Input is what ___, and output is what ___. For example, ___."

## Item 6

**Task:** A smart thermostat is set to 70 degrees, reads 65, and turns on the heat. What are the Input, Process and Output?

**Full credit needs:**
- [ ] **Input:** the 70-degree setting and the 65-degree reading
- [ ] **Process:** comparing them (65 is below 70)
- [ ] **Output:** turning on the heat

**Drops a tier:** the comparison left out, or the reading called the Output.

**Sentence starter (80-85%):** "The input is ___, the process is comparing ___, and the output is ___."

## Item 7

**Task:** A value, like a saved forecast or a calculated total, can be Output at one moment and Input later. Explain how, with an example.

**Full credit needs:**
- [ ] A program's output can be saved or passed along
- [ ] Another step or program then uses it as input
- [ ] An example shows both moments

**Drops a tier:** says it's possible without an example, or an example with only one moment.

**Sentence starter (80-85%):** "First ___ is output when ___. Later it becomes input when ___."

## Item 8

**Task:** If a program had Input and Output but no Process at all, what could it do? Explain with an example.

**Full credit needs:**
- [ ] It could only pass the input straight through, or do nothing useful with it
- [ ] An example where something needs working out (a total, a decision) that couldn't happen

**Drops a tier:** "it wouldn't work" with no explanation.

**Sentence starter (80-85%):** "Without a process, the program could only ___. For example, a ___ couldn't ___."

## Item 9

**Task:** A student says "the screen showing the number is the same thing as the computer doing the math." What's wrong, and how would you correct it?

**Full credit needs:**
- [ ] Doing the math is the Process
- [ ] Showing the number is the Output
- [ ] They are separate stages that happen one after the other

**Drops a tier:** says they're different without naming the stages.

**Sentence starter (80-85%):** "Doing the math is the ___, and showing the number is the ___."

## Item 10

**Task:** Pick a video game or app. Describe one Process step between your Input and the Output you see.

**Full credit needs:**
- [ ] A real game or app
- [ ] A specific Process step (checking a password, adding points, deciding a move)
- [ ] Placed correctly between a named Input and Output

**Drops a tier:** describes an input or output instead of a process.

**Sentence starter (80-85%):** "When I ___, the game has to ___ before it shows ___."
