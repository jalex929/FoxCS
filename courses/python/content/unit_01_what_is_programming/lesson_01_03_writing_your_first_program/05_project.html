01.3 Project: Startup Sequence

A short applied task before the mastery check. This one is about sequence, the core idea of this lesson: Python runs your lines in the exact order you write them, every time.

The Task

Write a sequence of print() statements that could believably be a game's startup sequence, in an order where the sequence itself matters. If you scrambled your lines, the result should stop making sense.

Requirements

  • At least 5 print() statements.
  • The order has to matter. Someone reading your sequence out of order should notice something is wrong (e.g. "Game starting..." appearing before "Loading save file...").
  • Run it and check the output matches what you predicted before running.
Game connection: This is a smaller version of what you did in this lesson's mastery check, applied to a scenario you invent yourself instead of one that's given to you.
Handoff to VS Code: Open 05_project.py in this same folder and write your sequence directly in it.

Don't forget to save your file (Ctrl+S) before you're done.
