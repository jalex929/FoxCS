01.5 Project: Documented Mini-Program

A short applied task before the mastery check. This one is about writing comments that explain why, not just restating what.

The Task

Open 05_project.py. It already has a short working program with no comments at all. Add a comment above each print() statement explaining why that line exists, as if you were leaving notes for a teammate who will read this code next week. Don't just restate what each line obviously does.

Requirements

  • Every print() statement gets a comment above it.
  • Each comment explains a reason, not just a description. ("# print the score" is too weak; "# show the score after each round so the player can track progress" is the target.)
  • Don't change what the program actually does. Only add comments.
Game connection: Real teams keep a shared codebase alive for years. The comments you write for a teammate today are often read by the same person, including you, long after the reason is no longer obvious.
Handoff to VS Code: Open 05_project.py in this same folder and add your comments directly in it.

Don't forget to save your file (Ctrl+S) before you're done.
