Unit Project

1.5.6a Project Instructions: Documented Mini-Program

A short applied task before the mastery check. This one is about writing comments that explain why, not just restating what.

The Task

Open 07_project.py. It already has a short working program with no comments at all. Add a comment above each print() statement explaining why that line exists, as if you were leaving notes for a teammate who will read this code next week. Don't just restate what each line obviously does.

What This Could Look Like

Here's the kind of comment quality this is asking for, applied to a line that isn't in your actual project file:

# remind the player of their goal before the timer starts
print("Find the exit before time runs out!")

Hint 1: For each line, ask yourself: "why would a real game show this, at this moment?" Your comment answers that question, not "what does print() do."

Hint 2: Start with just the first line. Write one comment, read it back, and ask: could someone who's never seen this file understand why this line matters just from your comment?

Hint 3: A shape to fill in, not the actual wording:

# [why does this line matter to a player, right now?]
print("Welcome back, Player!")
