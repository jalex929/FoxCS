FoxCS: Python. Game Programming I

Unit 01: What Is Programming?

Welcome to Unit 01. In Unit 00 you set up your tools and got your first look at how programmers think. Including the idea that every game is, underneath everything else, a program: a set of instructions a computer follows exactly, one step at a time. This unit is where that idea becomes real. By the end, you'll have written your first working Python programs, explained how they run, and built something that talks back to whoever is using it.

What You'll Learn

  • What a program actually is, and what it means to give a computer instructions
  • The Input → Process → Output pattern that every interactive program. Including every video game. Runs on
  • How to write and run your first real Python program
  • How to make your program talk to the screen using print()
  • How to leave notes for yourself and other programmers using comments
  • How to read Python's error messages instead of fearing them

Before You Start

Every lesson's files are numbered in the order you should do them: 01, 02, 03, and so on, right inside that lesson's folder. No subfolders to open first. If you're ever unsure what to do next, just look for the next number. Some lessons have more numbered steps than others (not every lesson has example code or an applied project step), but within a lesson, the numbers always run in order with nothing skipped.

You also don't need to rename anything or add your codename to any filename. Just work in the files you're given and save them where they are. Submit the whole Unit 01 folder when you're done with it.

Remember: save your work (Ctrl+S) after every change, before you close a file or move to the next one. An unsaved file is work that doesn't exist yet as far as anyone else can tell. Including you, tomorrow.
