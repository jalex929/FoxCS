VS Code Setup

Use a class desktop whenever you can. Every class desktop already has VS Code and the Python extension installed and ready to go, you don't need to set anything up there.

Only follow the steps on this page if you can't get to a class desktop, or you're having a technical problem and have to work on a Chromebook instead. This is a one-time setup, not something you do every day.

Opening a New Python File

VS Code doesn't know a file is meant to be Python just because you typed some code into it. You have to tell it. There are two ways to create a new Python file:

Method 1: File → New Text File

  1. Click File in the top menu, then New Text File.
  2. A blank file opens. In the bottom-right corner of the window, click where it says Plain Text (this is the language selector).
  3. Type Python and select it from the list that appears.

Method 2: File → New File

  1. Click File in the top menu, then New File...
  2. A list of file types appears. Choose Python File.

Either method works. Most of the time in this course, you'll already have a .py file given to you inside your lesson folder, you'll just open that one instead of creating a new one. Use the steps above when you actually need to create a new Python file yourself.

Installing the Python Extension (One Time Only)

VS Code needs one extra piece, called an extension, before it can really understand Python (things like color-coding your code and catching mistakes as you type). If you're on a class desktop, this is already installed. If you're setting up your own copy of VS Code, do this once and you won't need to do it again on that computer:

  1. Look at the strip of icons running down the left edge of the VS Code window. This is called the Activity Bar.
  2. Click the icon that looks like four small squares, with one of them pulled slightly apart from the rest, like a puzzle piece. This opens the Extensions panel.
  3. Type Python into the search box at the top of that panel.
  4. Find the extension simply named Python, published by Microsoft. It should be the first result.
  5. Click Install.

Saving Your Work

Save often, and always before you close a file or switch to something else. Press Ctrl+S (Windows and Chromebook) or Cmd+S (Mac). An unsaved file is work that doesn't exist yet as far as anyone else can tell, including you, tomorrow.

Save your file in the same lesson folder it came from, using the filename it already has. Don't move it somewhere else or rename it.
