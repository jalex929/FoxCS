01.6 Project: Bug Hunt Challenge

A short applied task before the mastery check. This one is your first real QA pass: a whole small program, broken in several places, that you have to fix line by line.

The Task

Open 04_project.py. It's supposed to print a short game intro, but every line has exactly one mistake from this unit's Big Four (missing quote, missing parentheses, wrong capitalization, missing quotes entirely). Fix every line so the program runs and produces the intended output shown in the comments.

Requirements

  • Fix every broken line. Don't just fix the first one and stop.
  • Run the file after each fix. A new error appearing means you fixed the one before it. That's progress, not failure.
  • Add a short comment above each line you fixed, naming which mistake it was.
Game connection: This is exactly what a QA pass looks like at a small scale: work through a list of known-broken things, one at a time, verifying each fix before moving to the next.
Handoff to VS Code: Open 04_project.py in this same folder and fix it directly.

Don't forget to save your file (Ctrl+S) before you're done.
