1.1.1 — Instruction: What Programs Do

Learning objectives:
  • I can explain what a program is, using an example from everyday life.
  • I can describe the role of a programming language and identify Python as one.
Language objective:
  • I can describe what a program is using the terms program, instruction, and programmer.

What Is a Program?

A program is a set of step-by-step instructions that a computer follows, exactly, in order. That's the whole idea. Everything else you learn this year is really just learning more powerful ways to write those instructions.

Think about a recipe. A recipe doesn't just say "make dinner." It breaks the task into exact steps: preheat the oven, chop the onion, add two cups of water. A cook who has never seen the dish before can still follow it, step by step, and produce the same result every time. A program does the same thing for a computer: it breaks a task into exact steps the computer can follow without needing to understand why, only what.

Quick Check
A recipe and a computer program are similar because they are both ___.

Computers Are Very Literal

This matters because computers are extremely literal. A computer does not guess what you probably meant. It does exactly what the instructions say, no more, no less. That's not a limitation to work around, it's the whole reason programs are useful. If a computer improvised, you couldn't trust it to do the same thing twice.

Real-World Example
A vending machine is a program too

A vending machine takes your money, checks whether you inserted enough, then either releases the item or shows an error. Every one of those checks and decisions was written ahead of time by a programmer as an exact instruction: "if the amount inserted is less than the price, do not release the item."

The machine isn't deciding anything in the moment. It's following instructions someone else already wrote, the same way a program running on any computer does.

Quick Check
A program's instructions say to add two numbers, but the programmer wrote the wrong numbers by mistake. What will the computer display when the program runs?

Where Python Fits In

Python is a programming language: a tool humans use to write instructions in a form a computer can actually carry out. There are many programming languages, the same way there are many spoken languages. They're different ways of writing the same kind of thing: precise, step-by-step instructions.

Game Connection
Every game you've ever played is a program

A game is a (very large) set of instructions: when the player presses this button, move the character that direction; when health reaches zero, show the game-over screen. Nothing in a game happens by magic or by the game "wanting" something to happen. Somewhere, a programmer wrote the exact instruction for it.

This whole course is about learning to write those instructions yourself, starting from the smallest possible piece.

Key Terms

program
A set of step-by-step instructions a computer follows, in order.
Example: A calculator app, a video game, and a weather app are all programs. Each one is a set of instructions a computer runs.
Think of it like: a recipe. A cook who has never made the dish before can still follow it exactly, step by step, and get the same result every time.
instruction
A single step in a program that tells the computer exactly what to do.
Example: "Display this message" or "check whether this number is bigger than zero" are each one instruction.
Think of it like: one line in a recipe, such as "preheat the oven to 350 degrees." A whole recipe is a series of instructions; so is a whole program.
programmer
A person who writes the instructions that make up a program.
Example: Every app, website, and game you've ever used was written by at least one programmer.
Think of it like: the person who writes a recipe, deciding exactly which steps a cook will need to follow.
Python
A programming language: a tool for writing instructions in a form a computer can carry out. The one this course uses.
Example: There are many programming languages, the same way there are many spoken languages. This course uses Python.
Think of it like: one specific language a recipe could be written in: English, Spanish, or French. Different languages, same idea: precise instructions.
