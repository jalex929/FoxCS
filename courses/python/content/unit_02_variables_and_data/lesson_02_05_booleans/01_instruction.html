What Is a Boolean?

A boolean holds exactly one of two values: True or False. No quotes, no other spellings.

game_paused = True
door_locked = False
Game Connection

Games are full of on/off state: is the game paused, is the player alive, is a level unlocked, is sound enabled, has an achievement been earned. Every one of these has exactly two possible states -- a natural fit for a boolean.

Quick Check
Which of these is a boolean?

Exact Casing Required

Python's booleans are capitalized, and only capitalized this one specific way: True and False. Not true, not TRUE.

sound_enabled = True   # correct
sound_enabled = true   # crashes -- Python looks for a variable named true, which doesn't exist

This is different from most other Python keywords, which are lowercase. Booleans are the exception -- capitalized, and case-sensitive about it.

Quick Check
Which of these is written correctly?

Booleans vs. Strings That Look Like Them

Just like numbers, booleans can be disguised as strings. The quotes always win.

paused = True      # a real boolean
state = "True"     # a string that happens to say True

"True" cannot be used the way a real boolean is used in your program's logic later this course -- it is text, full stop, regardless of what word is inside the quotes.

Usability Note

This mistake is easy to make when reading data from an outside source (a form, a file, a saved game) where everything often arrives as text. Reading "True" from a save file gives you the string, not the boolean -- something worth remembering once you start working with real saved data.

Quick Check
Is "False" (with quotation marks) the real Python boolean?

Booleans as Program State

A boolean's whole job is to represent one fact about your program that could go either way. Reading a boolean variable tells you something real about what's currently happening.

level_complete = False
print("Level Complete:", level_complete)

level_complete = True
print("Level Complete:", level_complete)

Reassignment (from Lesson 2.1) applies to booleans just like any other type -- flipping a boolean from False to True is exactly how a program remembers that something just happened.
