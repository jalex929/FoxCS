Creating a Variable

You create a variable with an assignment statement: a name, an equals sign, and a value.

lives = 3

This line does not ask "is lives equal to 3?" It creates a variable named lives and stores the value 3 in it. Once a variable exists, you can print it, change it, or use it anywhere else in the program.

lives = 3
print("Lives:", lives)

The variable name always goes on the left. The value it gets goes on the right. 3 = lives is not valid Python, even though it might read the same way out loud.

Text values need quotation marks around them. A number does not.

difficulty = "Normal"
lives = 3
Game Connection

Every piece of information a game has to track while it runs (score, health, lives, position, inventory) is a variable. When a game "remembers" that a player picked up a key three rooms ago, that memory is just a variable that has not changed since it was set.

Usability Note

A variable name is for you, the programmer. It is not automatically shown to anyone playing the game. If your code only ran print(health), the player would just see a bare number like 100 with no idea what it means.

Printing print("Health:", health) instead adds a label the player can actually understand. Choosing what to show, and how to label it, is a real design decision, not just a syntax detail.

Naming Your Variables

Python has real rules for what a variable name is allowed to be:

RuleValidInvalid
Must start with a letter or underscore, never a digitscore, _score2score
After that, only letters, digits, and underscores. No spaces.player_scoreplayer score

When a name needs more than one word, join the words with underscores. This style is called snake_case, and it is the standard way Python code names things.

Changing a Variable's Value

A variable is not locked to the value it started with. Assigning to the same name again replaces the old value. Python does not keep the old value anywhere once it is replaced.

lives = 3
print("Lives:", lives)

lives = 2
print("Lives:", lives)

That prints Lives: 3 and then Lives: 2. The second assignment did not create a second variable. It overwrote the first one.

Printing Variables With Text

You can join a variable with other text in two ways: with commas inside print(), or with the + operator, called concatenation.

Commas Example (no conversion needed):

player_name = "Rowan"
print(player_name, "is standing in the armory")

That prints Rowan is standing in the armory. Python adds a space between each piece automatically, and converts non-text values to text for you.

Concatenation (+) example:

player_name = "Rowan"
print(player_name + " is standing in the armory")

Same result: Rowan is standing in the armory. But + does not add spaces for you (you have to type them, inside the quotation marks), and every piece has to already be text.

Type Conversion

When you mix data types with + — joining text with a number, for example — you get an error.

Example Error:

score = 25
print("Your score is " + score)

Result:

TypeError: can only concatenate str (not "int") to str

Fixed Version:

score = 25
print("Your score is " + str(score))

Why? Python can only concatenate strings, so you must convert numbers using str() before combining them with text. A comma never runs into this: print("Your score is", score) works with no conversion needed, since a comma converts each piece for you.

Both methods are correct Python, and you will see both used in real code. A third method, called an f-string, is coming in a later lesson — once you are comfortable with commas and +, f-strings are usually the one professional Python code reaches for first.

A variable can hold different kinds of values. Here are the three you will see most in this unit:

KindExampleWritten as
Integer (a whole number)lives = 3plain digits, no quotes
String (text)difficulty = "Normal"wrapped in quotation marks
Boolean (true or false)is_game_over = TrueTrue or False, capitalized, no quotes
