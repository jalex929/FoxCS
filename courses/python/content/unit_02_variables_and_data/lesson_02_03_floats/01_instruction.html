What Is a Float?

A float is a number with a decimal point. Anywhere a value needs precision finer than a whole number, it's a float.

game_speed = 1.5
price = 4.99
temperature = 98.6
Game Connection

Game speed multipliers, elapsed time, and coordinate positions are almost always floats. A character doesn't move at exactly 2 pixels per frame forever -- a "1.5x speed boost" powerup needs a decimal to actually mean anything.

The Trickiest Case: A Float That Looks Whole

Here's the part of floats that catches people off guard:

average = 12.0

12.0 equals 12 mathematically. But in Python, the decimal point is what decides the type -- not the value. 12.0 is a float. 12 is an integer. Python treats them as two genuinely different kinds of value, even though they're mathematically equal.

Usability Note

This matters for how a value displays. A grade average of exactly 90 percent might come out of a calculation as 90.0 if any float was involved anywhere along the way -- worth knowing before you're confused by an extra .0 showing up on screen where you didn't expect one.

Choosing a Float on Purpose

Use a float whenever a value genuinely needs decimal precision: prices, percentages, measurements, ratios, anything between whole numbers.

price = 4.99
completion_percent = 87.5

Mixing Integers and Floats

When an integer and a float are combined in math, the result becomes a float. Python keeps the extra precision rather than throwing it away.

lives = 3
bonus = 0.5
print(lives + bonus)   # 3.5, not 3
