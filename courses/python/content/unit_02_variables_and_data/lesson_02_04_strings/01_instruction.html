What Is a String?

A string is text: letters, numbers, symbols, spaces -- anything -- wrapped in quotation marks.

player_name = "Rowan"
room = "the armory"
message = "You found 3 gold coins!"

Notice that last example: "You found 3 gold coins!" contains digits, but the whole thing is still one string, because the quotation marks wrap all of it.

Game Connection

Every piece of text a player actually reads -- dialogue, item names, room descriptions, menu options -- is a string. If a player can read it on screen, it's almost certainly text under the hood.

Quotes Override Appearance

This is the single most important rule about strings: whatever is inside quotation marks is text, no matter what it looks like. Python doesn't check the contents to decide the type -- it just checks for the quotation marks.

score = 100      # an integer
id_code = "100"  # a string -- looks numeric, is still text
paused = True    # a boolean
state = "True"   # a string -- looks like a boolean, is still text

Anything wrapped in quotes is a string. That includes numbers, the words True/False, even another variable's name spelled out. The quotes always win.

Usability Note

This is exactly why player_id = "042" from Lesson 2.2 works: even though it's all digits, wrapping it in quotes tells Python (and anyone reading the code) that this is an identifier to display, not a number to calculate with.

Quick Check
What type is "42" (with the quotation marks)?

A Variable Name vs. a Quoted Word

room and "room" look almost the same, but they mean completely different things to Python.

room = "kitchen"
print(room)     # kitchen -- prints the variable's stored value
print("room")   # room -- prints the literal word, quotes and all removed

Without quotes, Python looks up a variable and uses whatever value it's holding. With quotes, Python just uses the text exactly as written -- it never looks anything up.

Quick Check
x = "score" was created. What does print(x) actually print?

Numbers and Booleans in Disguise

Watch out for values that look like a number or a boolean but are actually strings:

count = "5"      # looks like an integer -- it's a string
flag = "True"    # looks like a boolean -- it's a string

These matter because a numeric-looking string does not do math the way you'd expect. "5" + "5" doesn't give you 10 -- it gives you "55", since + on two strings joins them together instead of adding.

Quick Check
What does print("5" + "5") actually print?
