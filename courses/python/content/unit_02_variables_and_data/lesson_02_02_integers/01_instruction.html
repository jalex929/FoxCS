What Is an Integer?

An integer is a whole number: no decimal point, no fraction. It can be positive, negative, or zero.

lives = 3
enemies_remaining = 8
temperature = -12
gold = 0

You write an integer as plain digits, with no quotation marks. Quotation marks turn a number into a string instead -- you'll practice telling those apart later in this lesson.

Game Connection

Score, lives, level, and inventory count are almost always integers. A game never has "2.5 lives" or "half an enemy" left -- these are things you count one at a time, so an integer is the right tool for the job.

Negative Integers

A minus sign in front of a whole number makes it negative. Negative integers are still integers -- they're just below zero.

debt = -50
altitude_below_sea_level = -200

Negative numbers show up more often than you might expect: a bank balance that's overdrawn, a temperature below freezing, or a score that went below zero after a penalty.

Quick Check
Is -9 an integer?

Integers vs. Text That Looks Like a Number

Quotation marks change everything. 10 and "10" look almost identical on the page, but Python treats them completely differently.

score = 10        # an integer -- Python can do math with this
player_id = "10"  # a string -- Python treats this as text, not a number

Mixing the two up causes real errors. If a value that should be a number ends up stored with quotation marks around it, math on it will fail.

Usability Note

Not everything that looks like a number should actually be stored as one. A player ID like "042" is usually kept as a string on purpose, even though it's made of digits -- nobody is going to add two player IDs together, and keeping the leading zero matters for display. Whether something is "a number" depends on whether your program needs to do math with it, not just what it looks like.

Basic Integer Arithmetic

Python does math on integers the way you'd expect, with one rule worth knowing early: multiplication and division happen before addition and subtraction, unless you use parentheses.

print(4 + 3 * 2)   # 10, not 14 -- 3 * 2 happens first
print((4 + 3) * 2) # 14 -- parentheses force the addition first

Reassignment (from Lesson 2.1) combines with arithmetic constantly -- a running total like a score or a health bar is usually just a variable being reassigned to itself, changed by some amount.

score = 5
score = score + 10
print("Score:", score)
