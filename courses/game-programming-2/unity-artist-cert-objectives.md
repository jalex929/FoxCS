# Unity Certified User: Digital Artist — Exam Objectives

**Source:** Official Unity Technologies exam objectives document, "Unity Exam Objectives - Digital Artist - Digital.pdf" (© 2022 Unity Technologies Incorporated), downloaded 2026-08-31 from https://certiport.pearsonvue.com/fc/unity/artist (Certiport-hosted, linked from Certiport's Unity Certified User "Objective domains" page). Reproduced here verbatim, not summarized or paraphrased.

**Naming note:** the real, current name is **"Unity Certified User: Digital Artist"** (confirmed both by the source PDF's own filename and by Jay's live GMetrix account catalog, 2026-08-31), not just "Artist" — use the full name in any FoxCS-facing content.

**Candidate profile (as stated in the source document):** The Unity Certified User Artist certification exam will test the basics of 2D and 3D digital artistry within Unity software to create interactivity in games, apps, AR/VR, and other experiences. Individuals will be expected to have at least 150 hours of Unity software use and training to obtain this certification.

## 1. Asset Management

1.1. Import assets including but not limited to settings for FBX, OBJ and associated textures.
1.2. Import and configure assets from the Unity Asset Store.
1.3. Slice spritesheets for use in a 2D scene including but not limited to using the default Sprite Editor and 9-slicing.
1.4. Identify mesh components including vertices, polygon faces and edges.
1.5. Create key frames and change tangents in the Curve Editor using the Animation window.
1.6. Create, modify and utilize Prefabs.

## 2. Scene Content Design

2.1. Utilize Transform tools and the Transform component in the Inspector.
2.2. Create prototype scenes using Unity primitives and/or low poly meshes utilizing white box/grey box techniques.
2.3. Create and edit a landscape with materials utilizing the Terrain tool including but not limited to mask maps, texture painting, and diffuse properties.

## 3. Lighting, Cameras, and Materials Implementation

3.1. Modify materials using the Standard Shader and editing properties including but not limited to specular, transparency, normal, and albedo.
3.2. Identify basic lighting including but not limited to shadows, light settings, and light shapes such as directional, area, spot, and point.
3.3. Utilize single camera set up including but not limited to isometric vs. standard, camera component, background, culling masks, clipping planes, field of view (FOV), etc.
3.4. Given a scenario, determine the appropriate rendering pipeline that should be used.

## Mapping note for FoxCS's Game Design/Unity pathway

This is the real target for any student on the art/design side of the Unity track (as opposed to the Programmer track): 2D/3D asset import and sprite work, scene-building with primitives/terrain, and lighting/camera/material/shader fundamentals. Domain 1's sprite-slicing and Prefab work pairs naturally with early 2D-project units; domain 3's shader/lighting/rendering-pipeline content is a real, distinct skill area not covered anywhere in the Programmer track's objectives.
