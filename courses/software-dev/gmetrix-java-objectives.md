# GMetrix / Certiport "Java" — Real Exam Objectives

**Source:** Jay's own licensed GMetrix account, Java Study Guide, read directly 2026-08-31 (`https://www.gmetrix.net/program/389/study-guide`). Real, complete 18-topic objective list. Jay has already completed this course and passed both practice exams himself.

Passing threshold per topic: **80% proficiency required** in each of the 18 topics below.

## Domain 1: Java Fundamentals
- 1.1 Describe the use of main in a Java application
- 1.2 Perform basic input and output using standard packages
- 1.3 Evaluate the scope of a variable
- 1.4 Comment and document programs

## Domain 2: Data Types & Structures
- 2.1 Declare and use primitive data type variables
- 2.2 Construct and evaluate code that manipulates strings
- 2.3 Construct and evaluate code that creates, iterates, and manipulates arrays and array lists
- 2.4 One- and two-dimensional arrays, including initialization, null, size, iterating elements, accessing elements; Collection Framework (ArrayList, Vector, Stack, LinkedList, HashSet) including adding and removing elements, traversing the list
- 2.5 Construct and evaluate code that performs parsing, casting, and conversion
- 2.6 Construct and evaluate arithmetic expressions

## Domain 3: Control Flow
- 3.1 Construct and evaluate code that uses branching statements
- 3.2 Construct and evaluate code that uses loops

## Domain 4: Object-Oriented Programming
- 4.1 Construct and evaluate class definitions
- 4.2 Declare, implement, and access data members in classes
- 4.3 Declare, implement, and access methods
- 4.4 Instantiate and use class objects in programs

## Domain 5: Debugging & Error Handling
- 5.1 Troubleshoot syntax errors, logic errors, and runtime errors
- 5.2 Implement exception handling

## Note for FoxCS's Software Dev pathway

This exam is notably **narrower and lighter than the existing `course-plan.md` SD-01 through SD-08 outline** — it has no dedicated inheritance/polymorphism/interfaces domain the way `course-plan.md`'s SD-06/SD-07 units do (OOP here stops at classes, data members, methods, and object instantiation — Domain 4). Matches Jay's "enough Java to pass" framing directly: the real exam doesn't require the deeper OOP-II content (inheritance/polymorphism/interfaces) the current course-plan already commits to teaching, so that content is enrichment beyond the exam floor, not exam-required.
