# GMetrix / Certiport "Software Development" — Real Exam Objectives

**Source:** Jay's own licensed GMetrix account, Software Development Study Guide, read directly 2026-08-31 (`https://www.gmetrix.net/program/390/study-guide`). This is the real, complete 21-topic objective list Certiport tests, not a summary or guess. GMetrix's own course catalog confirms "Software Development" is a real, separate, standalone Certiport IT Specialist exam, distinct from HTML5 Application Development, HTML and CSS, Java, and JavaScript (all also separate real exams under the same "Information Technology Specialist" umbrella).

Passing threshold per topic, per GMetrix: **80% proficiency required** in each of the 21 topics below.

## Domain 1: Programming Fundamentals
- 1.1 Understand computer storage and data types
- 1.2 Construct and analyze algorithms and flowcharts to solve programming problems
- 1.3 Incorporate error handling into applications or modules
- 1.4 Construct and analyze code based on functional programming patterns

## Domain 2: Software Development Lifecycle
- 2.1 Describe software development lifecycle (SDLC) management
- 2.2 Interpret application specifications
- 2.3 Construct and analyze code that uses algorithms and data structures
- 2.4 Describe the purpose of version control systems
- 2.5 Describe secure coding concepts

## Domain 3: Object-Oriented Programming
- 3.1 Construct, analyze, and use classes
- 3.2 Construct and analyze code that uses inheritance
- 3.3 Construct and analyze code that uses polymorphism

## Domain 4: Web Applications
- 4.1 Construct and analyze web applications
- 4.2 Describe and configure web hosting
- 4.3 Describe and configure web services
- 4.4 Describe and identify architectural patterns

## Domain 5: Databases
- 5.1 Design and normalize a database
- 5.2 Construct, analyze, and optimize ANSI SQL queries
- 5.3 Manage transactions
- 5.4 Describe database access methods
- 5.5 Describe types of NoSQL databases

## What this means for FoxCS's Software Dev pathway design

This exam is genuinely broader than "Java" — it spans programming fundamentals, SDLC/version control/secure coding, OOP (language-agnostic in the objectives themselves, though FoxCS teaches it via Java per the existing `course-plan.md`), web applications, and databases. This validates Jay's 2026-08-31 redesign direction (breadth across HTML/CSS + JavaScript + a major HTML5 App Dev project + enough Java to pass + Software Development concepts/projects) rather than a Java-only deep dive — the real exam objectives require exposure to web apps and databases regardless of how much Java depth a student reaches.
