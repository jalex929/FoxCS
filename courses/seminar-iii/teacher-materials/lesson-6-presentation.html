Session A

Variables, Expressions & Substitution

What a variable represents · reading and writing expressions · substituting to evaluate

What Is a Variable?

A letter can represent a number.

unknown valuechanging valuegeneral pattern
Example: a pay stub might read 15h, where h is hours worked. The value of h changes week to week, but the relationship stays the same.

Variable vs. Constant

One changes. One never does.

3x + 7
x is a variable, its value is not fixed. 7 is a constant, its value never changes here. 3 is a coefficient, the number that multiplies the variable.

Expressions vs. Equations

An expression has no equal sign.

3x + 7  is an expression.
3x + 7 = 22  is an equation.
An expression can be evaluated. An equation can be solved. Lesson 6 works only with expressions; solving begins in Lesson 7.

Reading an Expression

Say what the symbols mean.

4x + 9

"Nine more than four times a number."

Translating Words to Expressions

Match the phrase to the operation.

more than → addless than → subtracttimes, of → multiplyper, quotient → divide

Common Misconception

Does "five less than a number" mean 5 - x?

No. It reverses the order.

"Five less than a number" is x - 5, not 5 - x. Ask which quantity is actually being reduced.

Substitution

Replace the variable with its value.

If x = 4, then 3x + 2 becomes:
3(4) + 2 = 12 + 2 = 14

Substitution + Order of Operations

Substitute first, then follow PEMDAS.

Evaluate 2x² + 5 when x = 3
2(3)² + 5 = 2(9) + 5 = 18 + 5 = 23
Exponents are evaluated before multiplication.

Substitution With Negative Values

Parentheses protect the sign.

Evaluate 4x − 6 when x = −3
4(−3) − 6 = −12 − 6 = −18
Always place a substituted negative value in parentheses to avoid sign errors.

Substitution With More Than One Variable

Replace every variable, every time.

Evaluate 3a + 2b when a = 5, b = −4
3(5) + 2(−4) = 15 + (−8) = 7
Every occurrence of each variable must be replaced, not just the first one.

Exit Ticket · Session A

  1. Identify the coefficient, variable, and constant in an expression
  2. Translate a phrase into an expression
  3. Substitute and evaluate, including a negative value

Session B

Like Terms & the Distributive Property

Which terms can combine · multiplying every term inside a grouping symbol

Like Terms

Same variable, same power.

4x and 9x: like terms7y² and 2y²: like terms
4x and 4x² are not like terms (different powers). 3x and 3y are not like terms (different variables).

Combining Like Terms

Add or subtract the coefficients.

5x + 3x = (5 + 3)x = 8x
The variable part stays the same. Only the coefficients combine.

Combining Like Terms: Multiple Groups

Group the like terms first.

4x + 3 + 2x − 5
(4x + 2x) + (3 − 5) = 6x − 2

Combining Like Terms: Two Variables

Only combine matching variables.

3a + 5b − a + 2b
(3a − a) + (5b + 2b) = 2a + 7b
2a and 7b are not like terms, so the expression cannot simplify further.

The Distributive Property

The outside factor multiplies every term inside.

3(x + 4) = 3(x) + 3(4) = 3x + 12

Distributing a Negative Factor

The negative sign is part of the factor.

−2(x + 6) = −2(x) + (−2)(6) = −2x − 12
Watch sign changes closely when the outside factor is negative.

Common Misconception

Does 3(x + 4) equal 3x + 4?

No. The 3 must multiply both terms.

Incorrect: 3(x + 4) = 3x + 4. Correct: 3(x + 4) = 3x + 12.

Distribute, Then Combine Like Terms

Many expressions need both skills together.

4(x + 3) + 2x
4x + 12 + 2x
6x + 12

Exit Ticket · Session B

  1. Determine whether two terms are like terms
  2. Combine like terms in an expression with two variables
  3. Distribute and simplify one expression with a negative factor
