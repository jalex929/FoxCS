Seminar III · Unit 06 · Variables & Expressions

Letters That Stand for Numbers

This week's big question: What does this symbol represent, and how does its value change the result?

What Is a Variable?

A variable is a symbol, most often a letter, that stands in for a number. A variable can represent an unknown value to be found, a value that changes depending on the situation, or a general value used to describe a pattern or rule.

A pay stub might describe earnings as 15h, where h represents the number of hours worked. The value of h changes from week to week, but the relationship, earnings equal 15 times hours, stays the same.

Variable: a symbol representing a value that is unknown or that can change. Example: x, n, t.

Constant: a fixed value that does not change. In 3x + 7, the number 7 is a constant.

3x + 7  →  x is a variable. Its value is not fixed. 7 is a constant. Its value never changes in this expression. 3 is a coefficient, a number that multiplies the variable.

Coefficient: a number multiplied by a variable. In 3x, 3 is the coefficient of x. Term: a single number, variable, or product of numbers and variables, separated from other terms by addition or subtraction. 3x + 7 has two terms: 3x and 7.

Common Misconception A variable does not always mean "find this missing number." A variable can represent an unknown to solve for, but it can also represent a quantity that changes, such as hours worked or number of items purchased. Not every expression needs to be solved.

Reading and Writing Expressions

An expression is a mathematical phrase made of numbers, variables, and operations that represents a value. Examples: x + 4, 3x − 2, 2(x + 5). An expression does not contain an equal sign and does not claim that two quantities are equal.

Expression vs. Equation 3x + 7 is an expression. It represents a value and can be evaluated. 3x + 7 = 22 is an equation. It states that the expression equals a specific number, and can be solved. An expression without an equal sign cannot be solved, because there is nothing stating what it is equal to. Unit 06 works only with expressions. Solving equations begins in Unit 07.

Expressions can be translated into words and back. 4x + 9 can be read as "nine more than four times a number." 2(x − 3) can be read as "two times the difference of a number and three."

  • Addition: more than, increased by, sum, total, added to.
  • Subtraction: less than, decreased by, difference, fewer than, subtracted from.
  • Multiplication: times, product, of, twice, multiplied by.
  • Division: divided by, quotient, per, split into.
Common Mistake "Less than" and "subtracted from" reverse the order of the terms. "Five less than a number" is written x − 5, not 5 − x. "Five less than a number" and "five minus a number" describe different expressions: x − 5 means "five less than x," while 5 − x means "five minus x," or "a number less than five." Slow down and identify which quantity comes first in the actual subtraction.

Substituting Into an Expression

Substitute: to replace a variable with a given numerical value. Evaluate: to find the numerical value of an expression after substituting given values for the variables.

If x = 4, then 3x + 2 becomes 3(4) + 2 → 12 + 2 → 14.

Substitution must always be followed by the Unit 02 order of operations.

Evaluate 2x² + 5 when x = 3.  2(3)² + 5 → 2(9) + 5 → 18 + 5 → 23. Exponents are evaluated before multiplication.

Substituting a negative value requires careful use of parentheses.

Evaluate 4x − 6 when x = −3.  4(−3) − 6 → −12 − 6 → −18. Placing the substituted value in parentheses avoids sign errors.

Some expressions contain more than one variable. Every occurrence of each variable must be replaced.

Evaluate 3a + 2b when a = 5 and b = −4.  3(5) + 2(−4) → 15 + (−8) → 7.
Common Misconception In 3x + 2x, it is not true that only one x needs to be replaced. Every occurrence of the variable must be replaced with the given value.

Like Terms

Like terms contain the same variable raised to the same power. 4x and 9x are like terms. 7y² and 2y² are like terms. 4x and 4x² are not like terms, because they have different powers. 3x and 3y are not like terms, because they have different variables.

To combine like terms, add or subtract their coefficients. The variable part stays the same.

5x + 3x  →  (5 + 3)x → 8x
9y − 4y  →  (9 − 4)y → 5y
4x + 3 + 2x − 5  →  group like terms: (4x + 2x) + (3 − 5) → 6x + (−2) → 6x − 2
3a + 5b − a + 2b  →  group like terms: (3a − a) + (5b + 2b) → 2a + 7b. 2a and 7b are not like terms, so this cannot be simplified further.
Common Misconception 4x + 3x² cannot be combined into 7x or 7x². Terms can only be combined if they have the same variable raised to the same power. A related mistake is treating every number in an expression as a "coefficient": a coefficient multiplies a variable, while a constant stands alone with no variable attached. In 3x + 7, 3 is a coefficient and 7 is a constant.

The Distributive Property

The distributive property states that a factor outside a grouping symbol multiplies every term inside it.

3(x + 4)  →  3(x) + 3(4) → 3x + 12
5(x − 2)  →  5(x) − 5(2) → 5x − 10
−2(x + 6)  →  −2(x) + (−2)(6) → −2x − 12. Pay close attention to sign changes when the outside factor is negative.
Common Misconception Incorrect: 3(x + 4) = 3x + 4. Correct: 3(x + 4) = 3x + 12. The 3 must multiply both terms inside the parentheses, not only the variable term. The same is true for a negative factor: incorrect is −2(x + 6) = −2x + 6, correct is −2(x + 6) = −2x − 12. The negative sign is part of the factor being distributed and must multiply every term inside.

Putting It Together: Distribute and Combine

Many expressions require both distributing and combining like terms.

4(x + 3) + 2x  →  distribute: 4x + 12 + 2x → combine like terms: 6x + 12
2(3x − 1) − 4(x − 5)  →  distribute both groups: 6x − 2 − 4x + 20 → combine like terms: (6x − 4x) + (−2 + 20) → 2x + 18. Distribute the negative sign in front of −4(x − 5) carefully, since it changes the sign of both terms inside.

Expressions in Real Life

The examples below connect Unit 05's rate reasoning directly to Unit 06's expressions: the coefficient of the variable is often a rate.

  • Rental fee: a flat fee of $25 plus $8 per hour. Total cost for h hours: 25 + 8h.
  • Phone plan: $40 per month plus $0.10 per text message beyond a limit. Total cost for t extra texts: 40 + 0.10t.
  • Wages: a $12 hourly rate plus a $50 bonus. Total pay for h hours: 12h + 50.
  • Rideshare: a $3 base fee plus $2 per mile. Total cost for m miles: 3 + 2m.
Using the rental example, find the cost for 6 hours: 25 + 8(6) → 25 + 48 → 73. Answer: $73.

Does My Answer Make Sense?

Continue applying the Unit 02 reasonableness habit after evaluating or simplifying an expression.

SizeIs the evaluated result a realistic size for the situation?
SignShould the result be positive or negative?
SubstitutionWas the given value substituted into every occurrence of the variable?
Order of OperationsWere operations completed in the correct order after substitution?
Reasonableness Example A learner evaluates 25 + 8h for h = 6 and gets 198. This should look unreasonable. A quick estimate, 25 + 8(6) is about 25 + 50 = 75, shows the result should be close to 75, not 198. The likely cause is multiplying 8 by something other than 6, or adding before multiplying.

Calculators are useful for evaluating expressions with larger or decimal values and for checking substitution and arithmetic. Calculators cannot determine what a variable represents, whether an expression was translated correctly from words, whether like terms were correctly identified, or whether the distributive property was applied to every term.

Error Detective

Not every wrong answer means the same thing. Use the five error types from Unit 01 to diagnose what happened.

Knowledge: "I don't remember what a coefficient is." Response: review the vocabulary and definitions.
Process: a learner distributes correctly but combines unlike terms afterward. Response: review which terms qualify as like terms and retry.
Execution: a learner sets up substitution correctly but makes an arithmetic mistake evaluating the exponent. Response: check the calculation step by step.
Comprehension: a learner translates "five less than a number" as 5 − x instead of x − 5. Response: reread the phrase and identify which quantity is being reduced.
Strategy: a learner substitutes first without simplifying, creating unnecessary extra steps, when distributing first would have been faster. Response: consider whether simplifying before or after substitution is more efficient.
