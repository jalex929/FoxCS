Seminar III · Unit 06 · Variables & Expressions

Letters That Stand for Numbers

This week's big question: What does this symbol represent, and how does its value change the result?

What Is a Variable?

A variable is a symbol, most often a letter, that stands in for a number. A variable can represent:

  • An unknown value: a specific number you don't know yet.
  • A changing value: a quantity that is different in different situations.
  • A general value: a number used to describe a pattern or rule.

A pay stub might describe earnings as 15h, where h represents the number of hours worked. The value of h changes from week to week, but the relationship (earnings equal 15 times hours) stays the same.

A constant is a fixed value that never changes. In 3x + 7, x is a variable and 7 is a constant. The number 3, which multiplies the variable, is called a coefficient.

3x + 7: x is a variable, 7 is a constant, 3 is a coefficient.

Reading and Writing Expressions

An expression is a mathematical phrase made of numbers, variables, and operations that represents a value. An expression does not contain an equal sign and does not claim two quantities are equal.

4x + 9 can be read as: "Nine more than four times a number."
2(x − 3) can be read as: "Two times the difference of a number and three."

Translating in the other direction (words to symbols) uses the same operation clues:

  • Addition: more than, increased by, sum, total, added to.
  • Subtraction: less than, decreased by, difference, fewer than, subtracted from.
  • Multiplication: times, product, of, twice, multiplied by.
  • Division: divided by, quotient, per, split into.
Common Mistake "Less than" and "subtracted from" reverse the order of the terms. "Five less than a number" is written x − 5, not 5 − x. Slow down and identify which quantity comes first in the actual subtraction.

An expression is not the same as an equation. An equation is a statement that two expressions are equal, connected by an equal sign. 3x + 7 is an expression; it represents a value. 3x + 7 = 22 is an equation; it states that the expression equals a specific number. An expression can be evaluated. An equation can be solved. Unit 06 works only with expressions; solving equations begins in Unit 07.

Substituting Into an Expression

To substitute means to replace a variable with a given numerical value. To evaluate means to find the numerical value of an expression after substituting.

If x = 4, then 3x + 2 becomes 3(4) + 2 = 12 + 2 = 14.

Substitution must always be followed by the order of operations.

Evaluate 2x² + 5 when x = 3.
2(3)² + 5 → 2(9) + 5 → 18 + 5 = 23. Exponents are evaluated before multiplication.
Watch Out Substituting a negative value requires careful use of parentheses. Evaluate 4x − 6 when x = −3: 4(−3) − 6 → −12 − 6 = −18. Placing the negative value in parentheses avoids sign errors.

Some expressions contain more than one variable. Every occurrence of each variable must be replaced.

Evaluate 3a + 2b when a = 5 and b = −4.
3(5) + 2(−4) → 15 + (−8) = 7.

Like Terms

A term is a single number, variable, or the product of numbers and variables, separated from other terms by addition or subtraction. Like terms contain the same variable raised to the same power.

4x and 9x: like terms7y² and 2y²: like terms
Not Like Terms 4x and 4x² are not like terms (different powers). 3x and 3y are not like terms (different variables). Only terms with the same variable raised to the same power can combine.

To combine like terms, add or subtract their coefficients. The variable part stays the same.

5x + 3x = (5 + 3)x = 8x
9y − 4y = (9 − 4)y = 5y

Longer expressions may need several terms grouped before combining.

4x + 3 + 2x − 5 → (4x + 2x) + (3 − 5) = 6x − 2
3a + 5b − a + 2b → (3a − a) + (5b + 2b) = 2a + 7b (2a and 7b are not like terms, so this cannot simplify further)

The Distributive Property

The distributive property states that a factor outside a grouping symbol multiplies every term inside it.

3(x + 4) = 3(x) + 3(4) = 3x + 12
5(x − 2) = 5(x) − 5(2) = 5x − 10
Common Mistake Incorrect: 3(x + 4) = 3x + 4. Correct: 3(x + 4) = 3x + 12. The 3 must multiply both terms inside the parentheses, not only the variable term.

When the outside factor is negative, the sign changes on every term inside.

−2(x + 6) = −2(x) + (−2)(6) = −2x − 12

Putting It Together

Many expressions require distributing and then combining like terms.

4(x + 3) + 2x → 4x + 12 + 2x → 6x + 12

Longer problems may require distributing twice before combining.

2(3x − 1) − 4(x − 5)
→ 6x − 2 − 4x + 20
→ (6x − 4x) + (−2 + 20) = 2x + 18

The negative sign in front of −4(x − 5) must distribute carefully, since it changes the sign of both terms inside.

Expressions in Real Life

A rental company charges a flat fee of $25 plus $8 per hour. The total cost for h hours is 25 + 8h. Finding the cost for 6 hours: 25 + 8(6) = 25 + 48 = $73.

A phone plan costs $40 per month plus $0.10 per text message beyond a limit. The total cost for t extra texts is 40 + 0.10t.

These connect directly to Unit 05's rate reasoning: the coefficient of the variable is often a rate.

Does My Answer Make Sense?

Before trusting an evaluated result, check it against four things:

SizeIs the result a realistic size for the situation?
SignShould the result be positive or negative?
SubstitutionWas the value substituted into every occurrence of the variable?
Order of OperationsWere operations completed in the correct order after substitution?

Example: a learner evaluates 25 + 8h for h = 6 and gets 198. A quick estimate, 25 + 8(6) ≈ 25 + 50 = 75, shows the result should be close to 75, not 198. The likely cause is multiplying 8 by something other than 6, or adding before multiplying.

Error Detective

Not every wrong answer means the same thing. Use the five error types from Unit 01:

Knowledge: "I don't remember what a coefficient is." Response: review the vocabulary.
Process: distributing correctly but combining unlike terms afterward. Response: review which terms qualify as like terms.
Execution: setting up substitution correctly but making an arithmetic mistake with an exponent. Response: check the calculation step by step.
Comprehension: translating "five less than a number" as 5 − x instead of x − 5. Response: reread the phrase and identify which quantity is being reduced.
Strategy: substituting first without simplifying, when distributing first would have been faster. Response: consider whether simplifying before or after substitution is more efficient.
