# Percentage-to-Letter Grade Scale (School-Wide Reference)

Added 2026-09-08, prompted by building the student Grade Tracker template for Seminar III's Monday-style grade-check routine (see `01_SEMINAR_III_COURSE_PLAN`'s weekly structure and `decisions-log.md`'s 2026-09-08 entry). This is the cutoff table students use to translate a current percentage grade in any class into a letter grade.

| Letter | Percentage range |
|---|---|
| A | 89.5 – 100 |
| B | 79.5 – 89.499 |
| C | 69.5 – 79.499 |
| D | 59.5 – 69.499 |
| F | 59.499 and below |

**Source:** Jay, 2026-09-08, given directly for the student Grade Tracker build.

**Where this is used:**
- The Grade Tracker Google Sheet template (Seminar III Drive folder > Student Tools) implements this as a formula translating each week's typed-in percentage into a letter, in a protected column students can't overwrite.
- Any future Seminar III "grade check" activity (study hall grade-awareness routine) should use this same scale rather than inventing a different one.

This is a school-wide percentage scale, not specific to any one FoxCS course — treat it as authoritative for any future grade-report or grade-tracking tool across FoxCS courses unless Jay gives a different scale for a specific context.
