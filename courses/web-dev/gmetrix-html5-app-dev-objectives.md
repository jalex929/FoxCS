# GMetrix / Certiport "HTML 5 Application Development" — Real Exam Objectives

**Source:** Jay's own licensed GMetrix account, HTML 5 Application Development Study Guide, read directly 2026-08-31 (`https://www.gmetrix.net/program/391/study-guide`). Real, complete 17-topic objective list, not a summary or guess.

Passing threshold per topic: **80% proficiency required** in each of the 17 topics below.

## Domain 1: Application Lifecycle Management
- 1.1 Describe the application lifecycle management stages
- 1.2 Debug and test web apps

## Domain 2: Graphics
- 2.1 Use the canvas element to create graphics and animations
- 2.2 Use the svg element to create and display graphics
- 2.3 Transform, style, and enhance text and graphics
- 2.4 Apply CSS filters to images

## Domain 3: Forms
- 3.1 Construct and analyze markup that uses form elements
- 3.2 Configure input validation

## Domain 4: Layout (CSS)
- 4.1 Manage content layout, positioning, and flow by using CSS
- 4.2 Construct layouts by using responsive design
- 4.3 Construct flexible responsive layouts by using CSS flexbox
- 4.4 Construct grid-based layouts by using CSS grid

## Domain 5: JavaScript
- 5.1 Create and use custom classes
- 5.2 Perform data access by using JavaScript
- 5.3 Construct code that responds to events by using event listeners and handlers
- 5.4 Construct code that uses JavaScript APIs
- 5.5 Manage the state of an application

## What this means for FoxCS's Web Dev / Software Dev pathway design

This is the "major project" exam Jay's Software Dev redesign is building toward (HTML/CSS + JS skills feeding one major project that hits most of these objectives). Notably, this exam assumes real JavaScript proficiency (Domain 5: classes, data access, event handling, JavaScript APIs, state management) on top of HTML/CSS layout and forms — not a CSS-only exam. This should directly shape the "major project" scope: it needs to be a real, JS-driven interactive application (uses canvas/svg graphics, forms with validation, responsive CSS layout via flexbox/grid, and JS-managed state/events), not a static styled page.

**Relationship to the separate "HTML and CSS" exam** (also real, also in GMetrix's catalog): not yet checked in detail — likely a narrower prerequisite-level exam focused on markup/CSS fundamentals without the JavaScript/canvas/SVG depth this one requires. Worth pulling that exam's own objective list too before finalizing the Web Dev pathway's early-unit sequencing.
