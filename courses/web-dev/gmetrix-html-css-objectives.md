# GMetrix / Certiport "HTML and CSS" — Real Exam Objectives

**Source:** Jay's own licensed GMetrix account, HTML and CSS Study Guide, read directly 2026-08-31 (`https://www.gmetrix.net/program/386/study-guide`). Real, complete 17-topic objective list. Jay has already completed this course and passed both practice exams.

Passing threshold per topic: **80% proficiency required** in each of the 17 topics below.

## Domain 1: Page Markup
- 1.1 Construct markup that uses metadata elements
- 1.2 Construct well-formed page markup

## Domain 2: Style Sheets
- 2.1 Analyze and implement inline styles, internal (embedded) style sheets, and external style sheets
- 2.2 Construct and analyze rule sets

## Domain 3: Content Structure
- 3.1 Construct and analyze markup to structure content and organize data
- 3.2 Construct and analyze markup that uses HTML5 semantic elements
- 3.3 Construct and analyze markup that implements navigation
- 3.4 Construct and analyze markup that uses form elements

## Domain 4: Media
- 4.1 Construct and analyze markup that displays images
- 4.2 Construct and analyze markup that plays video and audio

## Domain 5: CSS Styling
- 5.1 Construct and analyze styles that position content
- 5.2 Construct and analyze styles that format text
- 5.3 Construct and analyze styles that format backgrounds and borders
- 5.4 Construct and analyze styles that create a simple responsive layout

## Domain 6: Quality & Standards
- 6.1 Construct well-formed HTML and CSS markup that conforms to industry best practices
- 6.2 Apply accessibility principles and evaluate content accessibility
- 6.3 Evaluate the structural integrity of HTML and CSS markup

## Relationship to "HTML 5 Application Development" (the other, separate exam)

Confirmed distinct: **this exam has zero JavaScript objectives** — it's pure markup/CSS fundamentals (metadata, semantic structure, forms, media, CSS positioning/text/backgrounds, a "simple" responsive layout, plus accessibility and best-practices/validation). HTML5 Application Development (see `gmetrix-html5-app-dev-objectives.md`) assumes this content as a prerequisite and adds real JavaScript depth (classes, events, APIs, state), canvas/SVG graphics, and advanced responsive layout (flexbox, CSS grid) on top of it. This confirms the natural FoxCS sequencing: HTML and CSS fundamentals first, HTML5 Application Development (the JS-driven major project) second — matches Jay's own stated redesign order (HTML/CSS toward the exam and what's practical, then JavaScript toward the exam, then the major HTML5 App Dev project).
